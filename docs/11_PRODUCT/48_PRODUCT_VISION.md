# Product Vision

# Visión General

Aula Robótica Platform está evolucionando desde un proyecto académico tradicional hacia una plataforma operativa colaborativa moderna orientada a:

- gestión del Aula de Robótica,
- coordinación de proyectos STEM,
- colaboración educativa,
- operación realtime,
- gestión organizativa,
- integración IAM universitaria.

La plataforma combina actualmente:

```text
Educational Platform
+
Operational Platform
+
Realtime Collaboration System
```

---

# Visión Principal

La visión dominante actual del producto combina tres dimensiones principales:

# 1. Plataforma Operativa del Aula de Robótica

El sistema actúa como:

```text
Operational Hub
```

para:

- proyectos,
- tareas,
- actividades,
- coordinación,
- trazabilidad,
- gestión diaria.

---

# 2. Plataforma Educativa Colaborativa

La plataforma permite:

- colaboración alumnado,
- coordinación docente,
- seguimiento proyectos,
- trabajo en equipo,
- aprendizaje basado en proyectos.

---

# 3. Plataforma Administrativa Realtime

Aunque todavía parcialmente emergente, el sistema ya incorpora:

- dashboards vivos,
- realtime collaboration,
- notifications,
- timelines,
- WebSockets,
- activity feeds.

Esto acerca progresivamente la arquitectura a una:

```text
Realtime Enterprise Admin Platform
```

---

# Filosofía del Producto

# No es un LMS clásico

La plataforma NO busca convertirse en:

- Moodle,
- Blackboard,
- Google Classroom.

# Objetivo real

El objetivo es construir:

```text
collaborative operational platform
```

más cercana a:

- Notion,
- Jira,
- Linear,
- Monday,
- plataformas operativas internas.

pero adaptada al contexto:

```text
educativo + robótica + proyectos STEM
```
